# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue or merge request.

Go to the Issues page of this project and select "New issue". Tick "Keep this issue
confidential" (shown as "This issue is confidential" in some versions) before you submit it.

## What to include

- A short description of the problem and its impact.
- The affected file, component, or endpoint.
- Steps to reproduce, or a proof of concept.
- The version or commit you tested against.
- Any suggested fix, if you have one.

## What to expect

We will acknowledge your report as soon as we can and keep you updated on progress.
Please do not disclose the problem publicly until a fix is available.

Our process is for a maintainer to review fixes before they are merged.

## About E-TAP

E-TAP is a triage assistant, not an oracle. Its verdicts help a person decide, and
they can be wrong. Treat its output as one input to your own judgement.
